1. Overview

This Privacy Policy describes how Crypto AI Assistant (the “Application”) handles information. The Application is personal, locally operated software for cryptocurrency market research, paper trading, risk analysis, and user-configured notifications. The public website is informational only and has no account, login, advertising, analytics, or tracking scripts.

The Application does not execute real cryptocurrency trades and does not connect to an OKX trading account.

2. Information collected

The local Application processes the following categories of information when the user enables or uses the relevant features:

  • OAuth authorization data: a Google OAuth access token, refresh token, client identifier, token endpoint information, granted scope, and expiry information needed to send mail through the Gmail API.
  • Notification configuration: whether Gmail and macOS notifications are enabled, the user-configured recipient email address, report schedule, risk thresholds, and price alerts.
  • Market and reference data: public cryptocurrency quotes, historical candles, calculated indicators, strategy signals, and USD/SGD reference rates.
  • Paper-trading and risk data: simulated account balances, positions, trades, prices, fees, reasons, and user-entered risk assumptions.
  • Operational records: synchronization status, task execution records, notification-delivery status, error messages, and locally generated reports.

The Application does not intentionally collect passwords, private cryptocurrency keys, seed phrases, real brokerage credentials, or real trading-account history.

3. Gmail API permissions and Google user data

The Application requests only this Google OAuth scope:

https://www.googleapis.com/auth/gmail.send

This permission is used solely to send user-configured market alerts, risk notifications, system-failure notices, and daily investment reports from the Google Account that the user authorizes. Email messages are sent only to the recipient address configured by the user.

The Application does not request or use permission to read the Gmail inbox, read message history, list contacts, inspect labels, manage drafts, delete email, or access unrelated Google Account data.

Google OAuth tokens are used only to authenticate Gmail API send requests. They are not sold, rented, used for advertising, or shared with data brokers. Information received from Google APIs is handled in accordance with the Google API Services User Data Policy, including its Limited Use requirements.

4. How information is used

Information is used to:

  • display market information and completed-candle technical analysis;
  • run historical strategy tests and paper-trading calculations;
  • calculate position risk, fees, profit and loss, and SGD estimates;
  • detect user-configured alerts and prevent duplicate notifications;
  • create local reports and, when enabled, send them through Gmail;
  • refresh an expired Gmail access token using the stored refresh token; and
  • diagnose data-source, authorization, delivery, and scheduled-task failures.

The Application does not sell personal information and does not use Google user data for advertising, credit decisions, surveillance, or training generalized artificial-intelligence models.

5. Local data storage and retention

The Application runs on the user’s Mac. Google OAuth token data is stored in the current user’s macOS Keychain. The downloaded OAuth client configuration is stored in a local secrets directory. Market data, reference exchange rates, notification settings, the configured recipient address, paper trades, notification history, task records, and error information are stored in a local SQLite database. Generated reports and operational logs are stored as local files.

These files are not uploaded to this public website or its GitHub repository. Repository ignore rules exclude the secrets directory, token or credential files, environment files, SQLite databases, logs, and generated investment reports.

Local information is retained until the user deletes it, removes the Application, clears the relevant macOS Keychain entry, or removes the Application’s local database, reports, and logs. Delivery copies sent through Gmail are retained under the sender’s and recipient’s Gmail settings and Google’s applicable policies.

6. Security measures

The Application uses the macOS Keychain for OAuth token storage, requests the narrow Gmail send-only scope, keeps credential files outside published source content, and does not place secrets in the website. The public website is delivered over HTTPS by GitHub Pages and contains no forms or client-side tracking scripts.

No security method is perfect. The user remains responsible for macOS account security, operating-system updates, local backups, repository review, and revoking access if the device or account may be compromised.

7. Third-party APIs and services

The local Application uses the following services:

  • Google Gmail API to send authorized notifications and reports;
  • Kraken public REST API for unauthenticated cryptocurrency quotes and candles;
  • Frankfurter API for the daily USD/SGD reference exchange rate; and
  • GitHub Pages to host this public informational website.

Requests to these providers may expose ordinary network information such as an IP address and request metadata to the provider. Their processing is governed by their own terms and privacy notices. The public website itself does not call Kraken, Frankfurter, or Gmail.

8. User control and revocation

The user can disable Gmail notifications in the local Dashboard, change the recipient and alert settings, or stop the scheduled tasks. Google authorization can be revoked from the Google Account’s third-party connections page. Revocation prevents future Gmail API sends until the user authorizes again.

To remove local data, the user can delete the Application’s macOS Keychain token and its local SQLite database, reports, logs, and OAuth client file. Deleting local paper-trading records is permanent and should be done only after any desired backup.

9. Children’s privacy

The Application is not directed to children and is not designed to knowingly collect children’s personal information.

10. Policy updates

This policy may be updated when the Application’s features, data handling, third-party services, or legal obligations change. The effective date and last-updated date at the top of this page will be revised. Material changes should be reviewed before continued use.

11. Contact information

For privacy questions or requests, open an issue in the public Crypto AI Assistant website repository. Do not include OAuth tokens, client secrets, cryptocurrency keys, personal reports, account details, or other sensitive information in a public issue.
